# Notes, Widgets, and Sandboxed MiniApps

## Overview

Phase 2/3 integration adds on-device Notes with SQLite FTS5 search, Glance/AppWidget home-screen widgets, and sandboxed WebView MiniApps generated by Finn. Everything runs locally with no telemetry.

## Notes (FTS5)

- Storage: `NativeNoteRepository` / `NoteRepository` backed by SQLite with an FTS5 virtual table for full-text search across titles, content, tags, and folders.
- UI: `NotesScreen` / `NotesViewModel` provide search, folder/tag filters, pins, and a note editor (`NoteEditorScreen`).
- Ingestion: `NoteIngestor` and `ShareReceiverActivity` save shared text/image/audio/video as notes.
- AI helpers: `NoteAi` organizes notes (title + tags) and provides an ASR prompt; `EngineExt` wires the on-device engine.

## Glance / AppWidget Widgets

- `QuickAskWidgetReceiver` and `RecentNotesWidgetReceiver` (Glance AppWidgets) declared in `AndroidManifest.xml`.
- Widget info XML in `res/xml/` (`quick_ask_widget_info.xml`, `recent_notes_widget_info.xml`).
- `FinnWidgets.kt` implements the Glance composables, reading recent notes and launching quick ask.

## Sandboxed WebView MiniApps

- `MiniAppRepository` stores generated apps (HTML) scoped per app.
- `MiniAppSanitizer` extracts fenced HTML, injects a strict Content-Security-Policy, strips network vectors (refresh, external links, iframes, scripts, CSS imports), and caps size.
- `MiniAppBridgeCore` exposes a scoped JS bridge (`FinnNative`) for storage (per-app KV), clipboard (gesture-gated), and rate-limited `askFinn`.
- `MiniAppWebView` / `MiniAppWebViewFactory` render apps in a hardened WebView: JS enabled, network loads blocked, file/content access disabled, mixed content never allowed, CSP enforced, URL interception allowing only the app origin + data/blob.
- `MiniAppsScreen` (`MiniAppsGallery` / `MiniAppHostScreen`) provides gallery + generation prompt and full-screen runner (`MiniAppRunner`).

## Navigation

`MainActivity` -> `AppShell` exposes Home, Chat, Live, Notes, MiniApps, Background Tasks, and Privacy Ledger destinations. Chat's history drawer reaches Tasks, Privacy Ledger, and Assistant setup.
